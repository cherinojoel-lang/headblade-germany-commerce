# HeadBlade Germany — Production Gate

Production is explicitly out of scope for the review-preview release.

No action may change `headblade.info`, DNS, production hosting, checkout, payment processing, customer-data capture, analytics, advertising, or live commerce until the owner gives a separate explicit production approval.

After owner approval, production work must start from the reviewed GitHub codebase and include a separate production configuration, commerce/payment integration review, legal/content verification, production SEO/indexing switch, analytics/consent review, rollback plan, and post-deploy verification.

The review-preview workflow must never be reused as an implicit production deployment.
