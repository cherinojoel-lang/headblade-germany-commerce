# HeadBlade Germany — Owner Review Checklist

Use the public review URL only after all automated release gates are green.

Review these points on desktop and mobile:

- Homepage hierarchy, typography, colors, spacing, imagery, and navigation
- Product overview, category pages, offers, finder, guide, legal pages, and 404 page
- Every product detail page, especially HeadBlade MOTO and blade compatibility information
- Product names, prices, compare-at prices, claims, bundle descriptions, and contact/company details
- No purchase, checkout, payment, order, or form can be completed in review mode
- No visible broken links, missing images, console errors, or unintended layout shifts
- Review banner clearly identifies the non-production state

Approval of the visual review does not deploy production automatically. Production requires a separate explicit owner instruction.
